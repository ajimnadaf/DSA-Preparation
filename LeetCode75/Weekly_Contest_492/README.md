# LeetCode Weekly Contest 492 Solutions

This repository contains my solutions for **LeetCode Weekly Contest 492**.

## Problems

1. **Minimum Capacity Box** (Easy)

   * Find the smallest box capacity to fit an item.
   * File: `Q1_MinimumCapacityBox.cpp`

2. **Find the Smallest Balanced Index** (Medium)

   * Find an index where left sum equals right product.
   * File: `Q2_SmallestBalancedIndex.cpp`

3. **Minimum Operations to Sort a String** (Medium)

   * Sort substrings to make the whole string non-descending.
   * File: `Q3_MinimumOperationsToSortString.cpp`

4. **Minimum Cost to Partition a Binary String** (Hard)

   * Partition a binary string to minimize encoding/flat cost.
   * File: `Q4_MinimumCostPartitionBinaryString.cpp`

## Notes

* Solutions are written in **C++**.
* Q4 uses **DP + prefix sum + memoization** for optimization.
